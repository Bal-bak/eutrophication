# Интеллектуальная система мониторинга и прогнозирования эвтрофикации водоёмов Беларуси

Командный курсовой проект (4 участника). Система объединяет **реальные спутниковые данные Sentinel-2 L2A**, **суточную погоду NASA POWER**, **машинное обучение**, **семантическую базу знаний (W3C SOSA/SSN)** и **веб-ГИС интерфейс** для прогноза эвтрофикации и риска цветения водоёмов на горизонт **10 дней**.

## Архитектура по 4 частям команды
1. **Часть 1 — Сбор данных, ETL и витрина признаков (`src/etl/`, `configs/`):** реальные полигоны озёр OSM, выгрузка пикселей Sentinel-2 L2A (`NDCI`, `NDTI`, `SCL`), метеоданные NASA POWER (`2020–2026`), контроль качества данных и построение витрины признаков (`features_dataset.parquet`).
2. **Часть 2 — Машинное обучение (`src/models/`):** хронологическое обучение и верификация моделей регрессии и классификации на горизонт `+10` дней.
3. **Часть 3 — Семантическая база знаний (`src/knowledge_graph/`):** онтология `OWL/RDF` (`W3C SOSA/SSN`), продукционные правила оценки риска (`GREEN/YELLOW/RED`) и SPARQL-запросы.
4. **Часть 4 — API и веб-ГИС интерфейс (`src/api/`, `frontend/`):** FastAPI-сервис и интерактивная карта озёр с прогнозами и объяснениями.
